# Estudos de Java

Este repositório armazena resoluções de exercícios, desafios de lógica e projetos desenvolvidos durante os meus estudos na linguagem Java. O objetivo é registrar minha evolução e manter um histórico técnico de aprendizado.

## Ambiente de Desenvolvimento

- Linguagem: Java (versão 17)
- IDE: VS Code / IntelliJ IDEA
- Controle de Versão: Git e GitHub

## Conteúdos e Exercícios

Abaixo estão listados os tópicos abordados nos exercícios resolvidos até o momento:

- [x] Estrutura Sequencial (Entrada, processamento e saída de dados)
- [x] Estruturas Condicionais (if, else, switch-case)
- [ ] Estruturas de Repetição (while, for, do-while)
- [ ] Arrays e Matrizes (Vetores de dados)
- [ ] Programação Orientada a Objetos (Classes, atributos e métodos)
- [ ] Pilares da POO (Herança, encapsulamento e polimorfismo)
- [ ] Tratamento de Exceções (try-catch)

*Nota: Os tópicos marcados com [x] representam conteúdos já praticados no repositório.*

## Como Executar os Projetos

Para rodar qualquer um dos exercícios no seu computador, você precisará ter o **JDK (Java Development Kit)** instalado.

1. Clone este repositório:
   ```bash
   git clone https://github.com/RianNovaes/Java-estudos
   ```
2. Navegue até a pasta do exercício desejado.
3. Compile o arquivo `.java`:
   ```bash
   javac NomeDoArquivo.java
   ```
4. Execute o programa:
   ```bash
   java NomeDoArquivo
   ```
